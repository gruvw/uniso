How do I get the notes into my DAW or synth?

A web page can't register itself as a MIDI device, so it sends to an existing port. Create a virtual MIDI cable, pick it above as the output, and pick the same port as the MIDI input in your DAW or synth.

  • macOS: open Audio MIDI Setup → Window → Show MIDI Studio → double-click IAC Driver → tick Device is online.
  • Windows: install loopMIDI (Tobias Erichsen) and add a port with the + button.
  • Linux: sudo modprobe snd-virmidi, or use a JACK / PipeWire MIDI bridge.

Keys only play while this browser tab has focus. Use Chrome, Edge or Opera. Middle C (MIDI 60) is shown as C4; some DAWs (e.g. Ableton Live) call it C3.
